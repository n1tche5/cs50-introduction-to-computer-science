# 🎓 CS50x: Introduction to Computer Science

## 📝 Description
This repository serves as my personal code archive and portfolio for Harvard University's renowned **CS50x: Introduction to Computer Science** course. 🚀 

CS50x is a rigorous entry-level course that introduces foundational concepts of computer science and the art of programming. Through this journey, I am developing strong problem-solving skills and learning how to think algorithmically to solve complex real-world problems. 🧑‍💻

This space tracks my academic progression, featuring my implementations for weekly problem sets, labs, and comprehensive software projects.

---

## 📚 Course Curriculum & Progress

- **Week 0: Scratch** 🐱
  * Fundamentals of computational thinking, loops, conditions, and variables.
- **Week 1: C** 🪙
  * Introduction to strongly-typed programming languages, syntax, compilation, and data types.
- **Week 2: Arrays** 📊
  * Compiling, debugging, cryptography basics, and manipulating data sequences in memory.
- **Week 3: Algorithms** 🔍
  * Searching (Linear, Binary) and sorting (Bubble, Selection, Merge) algorithms, alongside asymptotic notation.
- **Week 4: Memory** 💾
  * Pointers, hexadecimals, addresses, and dynamic memory allocation (`malloc`, `free`).
- **Week 5: Data Structures** 🌲
  * Building and managing custom structures: Linked Lists, Hash Tables, and Tries.
- **Week 6: Python** 🐍
  * Transitioning to a high-level, dynamically-typed language and rewriting algorithmic solutions.
- **Week 7: SQL** 🗄️
  * Designing, querying, and managing relational databases.
- **Week 8: HTML, CSS, JavaScript** 🌐
  * Front-end web development, building UI layouts, and adding browser interactivity.
- **Week 9: Flask** 🌶️
  * Back-end web frameworks, dynamic routing, and handling web requests.
- **Week 10: Cybersecurity** 🔒
  * Understanding vulnerabilities, security mindsets, and safe coding practices.
- **Final Project** 🚀
  * A capstone full-stack software project applying everything learned throughout the course.
